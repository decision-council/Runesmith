Every rune is a fingerprint

Each rune on this page is drawn from a real SHA-256 hash, the fingerprint of a file. The same file always gives the same rune. Change one letter, and the rune changes. Try it: type your name, a word, or a hash from the receipts.

How a rune is drawn

A rune starts as a stave, one upright line. The hash's first bytes then choose 2 to 4 twigs: where each one starts, which way it leans, and whether it bends back. One rune in four is mirrored, and some carry a spark. Text is hashed first. A 64-character hash is used as it is.

A rune is a quick check for the eye, not a proof. Two different files can share a rune, but they will not share a hash. For proof, compare the full SHA-256.
